## 1. Metodología de trabajo

- **Repositorio:** el líder creara el repositorio en GitHub con su cuenta institucional y vincula a todos los integrantes.

- **Trabajo en equipo:** cada tarea tiene un responsable, pero se revisa por todo el grupo antes de darla por terminada.

## Estructura obligatoria del repositorio

| Carpeta | Contenido |
| :--- | :--- |
| `src/` | Código fuente |
| `docs/` | Documentación y actas |
| `images/` | Logo y diagramas |
| `data/` | Peticion.txt, Queja.txt, Reclamo.txt, Sugerencia.txt |

---

## 3. Toma de decisiones y resolución de conflictos

1. Las decisiones se toman por **mayoría** de votos.
2. Ante un desacuerdo se busca un punto medio.
3. Si no hay solución, se consulta al docente **Victor Hugo Mercado**.

---

## 5. Seguimiento y revisión

- **Reuniones de seguimiento:** en ellas se revisa el avance, se aclaran dudas, se ajustan tareas y se actualizan estas actas si hace falta.
- **Resolucion de dudas** Se aclaran dudas de los deberes, las dificultades de las tareas asignadas se aclaran implementando cualquier metodo que nos permita dar solución.
